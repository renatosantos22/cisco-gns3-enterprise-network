DUAL STACK nos routers e nos ipterms.

Com os tuneis 6to4 não é necessário OSPFv3. O túnel é inteligente o suficiente para extrair o IPv4 de destino diretamente do endereço IPv6.

O ping para o Google (2001:4860...) não vai funcionar com 6to4 porque o 6to4 foi desenhado para ligar "ilhas" IPv6 através de um "oceano" IPv4. Os pacotes ganham o prefixo especial 2002::/16. Para um pacote 2002:: conseguir chegar a um IP nativo 2001:: (como o Google), ele precisaria de encontrar um Relay Router 6to4 na Internet pública. Como no teu GNS3 não tens um ISP IPv6 configurado com Relay, a conectividade fica restrita às tuas ilhas internas. No entanto isso é tudo o que o Ponto 14 pede, o guião exige demonstrar a transição com túneis dinâmicos.

A Matemática Magica do 6to4
Para os túneis dinâmicos, o prefixo IPv6 é gerado convertendo o IP da interface IPv4 (Ethernet0/0) para Hexadecimal.

CC-R01 (IPv4: 10.0.4.2): 10 = 0A, 0 = 00, 4 = 04, 2 = 02.

Prefixo Base: 2002:0A00:0402::/48 (Simplificado: 2002:A00:402::/48)

CC-R03 (IPv4: 10.0.4.5): 10 = 0A, 0 = 00, 4 = 04, 5 = 05.

Prefixo Base: 2002:0A00:0405::/48 (Simplificado: 2002:A00:405::/48)

Configurar o CC-R01 (Túnel Dinâmico). Vamos atribuir o Subnet ID 1 e 2 às respetivas 2 LANs e criar o Túnel no router:

conf t

! 1. Endereçar as LANs com o novo prefixo 6to4 do CC-R01
interface Ethernet0/1
 ipv6 address 2002:a00:402:1::1/64
interface Ethernet0/2
 ipv6 address 2002:a00:402:2::1/64
exit

! 2. Criar o Túnel Dinâmico (Nota que NÃO há tunnel destination!)
interface Tunnel0
 ipv6 unnumbered Ethernet0/0
 tunnel source Ethernet0/0
 tunnel mode ipv6ip 6to4
exit

! 3. A Rota Dinâmica (Qualquer tráfego 6to4 vai para o túnel)
ipv6 route 2002::/16 Tunnel0

Configurar o CC-R03 (Túnel Dinâmico). Exatamente a mesma lógica, mas com o prefixo do CC-R03:

conf t

! 1. Endereçar as LANs com o novo prefixo 6to4 do CC-R03
interface Ethernet0/1
 ipv6 address 2002:a00:403:1::1/64
interface Ethernet0/2
 ipv6 address 2002:a00:403:2::1/64
exit

! 2. Criar o Túnel Dinâmico
interface Tunnel0
 ipv6 unnumbered Ethernet0/0
 tunnel source Ethernet0/0
 tunnel mode ipv6ip 6to4
exit

! 3. A Rota Dinâmica
ipv6 route 2002::/16 Tunnel0

Estratégia de Transição: O mundo não mudou de IPv4 para IPv6 de um dia para o outro. Durante muitos anos, as operadoras tinham núcleos de rede apenas em IPv4, mas os clientes queriam usar IPv6. O 6to4 foi criado exatamente como uma "estratégia de transição" para permitir que redes IPv6 (ilhas) comunicassem por cima de infraestruturas antigas IPv4 (o oceano), encapsulando o pacote IPv6 dentro de um pacote IPv4.

Dinâmicos: São chamados túneis dinâmicos porque, ao contrário de um túnel GRE normal (onde tens de escrever explicitamente tunnel destination 10.0.4.5), no 6to4 o router faz as contas sozinho. Quando fazes ping a 2002:0A00:0405..., o router vê o 2002:, sabe que é um túnel 6to4, extrai o 0A00:0405, converte para 10.0.4.5 e cria o túnel no momento (dinamicamente) para esse IP!

Só servem para ligar estas 4 sub-redes pela infraestrutura IPv4 porque o objetivo deste túnel na topologia é exclusivamente atuar como uma ponte invisível sobre os cabos do teu resort. Para o tráfego IPv6, é como se os routers CC-R01 e CC-R03 estivessem ligados por um cabo direto, ignorando completamente que pelo meio existe OSPF, routers intermédios, etc.

Fico restrito apenas a comunicar com coisas que têm IPv6 configurado porque o tráfego IPv6 só sabe falar com endereços IPv6. Como o teu Edifício Administrativo Central (EAC) ou a Restauração (R) não têm IPv6, não consegues fazer um ping6 do CC para lá.
Mas atenção: Como usaste a técnica de Dual-Stack (Pilha Dupla), os teus ipterms e routers no CC têm ambos os protocolos ativos (têm um IP 194.65.x.x e um IP 2002:x:x...).

Se o utilizador no CC quiser aceder a um PC na sua própria unidade, o PC usa IPv6.
Se quiser aceder à Internet (ISP) ou ao EAC, o PC usa o seu endereço IPv4 normal.

A implementação está restrita ao Centro de Conferências, tem endereçamento IPv6, usa uma estratégia de transição baseada em Dual-Stack e tunneling e usa túneis dinâmicos 6to4.
